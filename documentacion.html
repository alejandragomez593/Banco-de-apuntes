1. Descripción general

Banco de Apuntes es una aplicación web para compartir, buscar y gestionar materiales de estudio de bachillerato. Resuelve la dispersión de apuntes en chats y carpetas personales con una biblioteca organizada, con autoría y búsqueda. El análisis de mercado, competidores y marketing está en la página Modelo.

3. Arquitectura

Aplicación de front-end con HTML, CSS y JavaScript sin librerías. Los datos se guardan en localStorage. Archivos principales:

  • js/store.js: capa de datos y seguridad (usuarios, sesión, CRUD de materiales).
  • js/app.js: navegación, biblioteca (búsqueda, filtros, favoritos, vista previa) y modo oscuro.
  • js/pages.js: lógica de registro, login, panel, formulario y reportes.
  • js/seed.js: lista de los 30 recursos base para los reportes.

4. Modelo de datos

EntidadCampos

Materialid, title, subject, type, description, content, tags, ownerId, author, created, updated, views

Relación: un usuario puede tener muchos materiales (1:N mediante ownerId).

5. Seguridad básica

  • Contraseñas guardadas como hash PBKDF2-SHA256 con sal; nunca en texto plano.
  • Política de contraseña: 8+ caracteres con mayúscula, minúscula y número.
  • Bloqueo de 1 minuto tras 5 intentos fallidos de inicio de sesión.
  • Sesión con expiración por 30 minutos de inactividad.
  • Páginas protegidas (panel, subir, reportes) redirigen al login; los permisos por rol impiden editar o eliminar materiales ajenos.
  • Texto de usuarios escapado antes de mostrarse (prevención de XSS) y validación de entradas.
  • Redirección posterior al login limitada a páginas internas.

Limitación: al ser una versión sin servidor, la validación ocurre en el navegador. En producción las reglas deben repetirse en un backend con base de datos y HTTPS.

6. Guía de uso y credenciales de prueba

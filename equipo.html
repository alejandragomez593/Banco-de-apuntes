Preguntas frecuentes

¿Quieres saber algo más?

¿El proyecto ya tiene una base de datos?

Esta versión guarda usuarios y materiales en el navegador (localStorage). Para compartirlos entre dispositivos se necesitaría conectar un backend y una base de datos.

¿Los materiales son oficiales?

No. Los recursos incluidos son ejemplos para mostrar cómo funcionaría la biblioteca.

¿Puedo usar la página desde mi celular?

Sí. El diseño se adapta a pantallas pequeñas y grandes.

¿Cómo se deben compartir materiales?

Solo deben compartirse recursos propios o aquellos que se tenga permiso de distribuir.
